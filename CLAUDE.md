# Projekt: vizitka

Osobní webová vizitka Tomáše (Anesys). Jedna statická stránka `index.html`, žádné sestavování ani knihovny.

## Jak tu pracovat
- Barvy se mění přes CSS proměnné s českými názvy v `:root` (hlavní barva antracitová).
- Texty piš tónem z knowledge base (skill muj-kontext): formálně, ale přátelsky.
- Po každé povedené změně: ulož verzi a pošli na GitHub (repozitář Kertis13/vizitka, veřejný). Vercel web obnoví sám.
- Na hlavě koníka v hlavičce je „osobnost" na přání majitele, neodstraňovat bez pokynu.
